# Minha Loja

Projeto de faculdade: página de uma loja virtual feita com HTML, CSS e JavaScript puro, sem frameworks. A página é responsiva (celular, tablet e notebook) e tem:

- vitrine com 6 produtos, com nome e preço;
- aviso de frete (frete grátis a partir de R$ 200);
- menu que abre e fecha no celular;
- formulários de contato com validação simples dos campos.

## Como abrir

1. Baixe ou clone o projeto:
   ```
   git clone https://github.com/lucasvargass/projeto-ecommerce-faculdade.git
   ```
2. Abra a pasta e dê dois cliques no arquivo `index.html`. Ele abre direto no navegador, sem precisar instalar nada.
